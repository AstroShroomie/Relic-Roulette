# Relic Roulette

**A Twitch chaos mod for Tomb Raider I–III Remastered — mod by AstroShroomie.**

Chat votes on what happens next to Lara: boulders, darts, Thor's hammer, enemies, camera tricks and plenty more.

## Download

Get the newest zip from the [Releases](https://github.com/AstroShroomie/Relic-Roulette/releases/latest) page, unzip it anywhere, and run **Relic Roulette.exe**. Press **Install**, then **Start**.

Already have it? Open Relic Roulette and press **Update** when it offers a new version. Your settings, Twitch sign-in and installed levels are kept.

## Good to know

- **Built for tank controls.** If you play with modern controls, some effects may not work fully. Switch to tank controls in the game's settings for the full experience.
- Install changes the 45 Tomb Raider I level files in your Steam folder. The originals are backed up first, and **Remove** puts them back exactly.
- Windows may warn about the download the first time, because the program is not code-signed.
- The full source of the app and its tools is inside the zip. Relic Roulette is free software under the GPL-3.0 licence, with no warranty.
